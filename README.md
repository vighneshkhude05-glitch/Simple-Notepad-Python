
# Simple Notepad Application Using Python

## About the Project
This is a simple Notepad application developed using Python and the Tkinter library. It provides a graphical user interface (GUI) that allows users to create, open, edit, and save text files easily.

This project is suitable for beginners who want to learn Python GUI development and file handling.

## Features
- **New File:** Create a new blank document.
- **Open File:** Open existing text files.
- **Save File:** Save text to the current file.
- **Save As:** Save a file with a new name or location.
- **Text Editor:** Write and edit text.
- **Scrollbar:** Navigate through long documents.
- **Error Handling:** Display error messages if a file cannot be opened or saved.
- **Exit:** Close the application.

## Technologies Used
- Python 3
- Tkinter
- File Handling
- Message Box and File Dialog

## Requirements
- Python 3 installed on your computer.
- Tkinter library (included with most standard Python installations).

## How to Run the Project
1. Clone or download this repository.
2. Open the project folder in VS Code or a terminal.
3. Run the following command:

   ```bash
   python notepad.py
   ```

4. The Notepad application window will open.
